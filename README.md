# 🎵 Spotify Remote: iPod Nano Edition

Это проект "под ключ" для создания физического пульта управления музыкой Spotify в стиле классического iPod Nano. Проект работает на микроконтроллере **ESP32-C3 Super Mini** с дисплеем **ST7735 (0.96", 80x160)**.

Устройство подключается к вашему Wi-Fi и через Spotify Web API позволяет:
- Видеть текущий трек, исполнителя и обложку альбома.
- Переключать треки (вперед/назад).
- Ставить на паузу / запускать воспроизведение.
- Ставить лайк (❤️) текущему треку.

---

## 🛠 Железо и распиновка

Вам понадобятся:
1. **ESP32-C3 Super Mini**
2. **Цветной дисплей ST7735 0.96" (80x160)**
3. **5 тактовых кнопок**

### Подключение дисплея (SPI)
- **MOSI** (SDA) -> GPIO 7
- **SCLK** (SCL) -> GPIO 6
- **CS** -> GPIO 10
- **DC** -> GPIO 20
- **RST** -> GPIO 21
- **BL** (Подсветка) -> GPIO 8 (или напрямую к 3.3V)
- **VCC** -> 3.3V
- **GND** -> GND

### Подключение кнопок
Кнопки подключаются одним контактом к GPIO, вторым контактом к **GND** (используется внутренняя подтяжка).
- **Вверх (Menu)** -> GPIO 0
- **Вниз (Play/Pause)** -> GPIO 1
- **Влево (Prev)** -> GPIO 3
- **Вправо (Next)** -> GPIO 4
- **Центр (Select/Like)** -> GPIO 5

## ⚡ Прошивка (Установка в 1 клик)

Вам **не нужно** скачивать код или устанавливать Arduino IDE!

1. Подключите вашу ESP32-C3 к компьютеру по USB.
2. Откройте браузер Google Chrome или Microsoft Edge (Safari и Firefox не поддерживают Web Serial API).
3. Перейдите на страницу веб-установщика: https://danmilk227.github.io/Spotify_remote-/
4. Нажмите **"Install"**, выберите порт с вашей ESP32 и дождитесь окончания прошивки.

## 🔑 Получение ключей Spotify

Чтобы пульт мог управлять вашей музыкой, вам нужно создать "Приложение" в Spotify Developer Dashboard.

1. Зайдите на [Spotify Developer Dashboard](https://developer.spotify.com/dashboard) и войдите под своим аккаунтом.
2. Нажмите **"Create app"**.
3. Заполните поля:
   - **App name**: iPod Remote
   - **App description**: My physical remote
   - **Redirect URI**: `https://developer.spotify.com/` (Это нужно только для первичного получения токена).
   - Поставьте галочку согласия с правилами и нажмите **Save**.
4. Зайдите в созданное приложение и нажмите **Settings**. Скопируйте **Client ID** и **Client Secret**.

### Получение Refresh Token (Только один раз!)
Чтобы устройство могло автономно обновлять доступ к Spotify, нужен **Refresh Token**. Самый простой способ его получить — использовать онлайн генераторы (например, [Spotify Refresh Token Generator](https://get-spotify-token.netlify.app/) или через Postman), используя ваши `Client ID` и `Client Secret` и запросив scope:
`user-read-playback-state user-modify-playback-state user-library-read user-library-modify`.

## 🚀 Первое включение и настройка

1. После прошивки включите ESP32-C3. На экране появится заставка "iPod Spotify Edition".
2. Устройство не найдет знакомую Wi-Fi сеть и создаст свою точку доступа: **`iPod-Nano-Setup`**.
3. Возьмите телефон, подключитесь к Wi-Fi **`iPod-Nano-Setup`** (если появится окно авторизации, введите пароль от вашего домашнего Wi-Fi).
4. На экране плеера появится IP-адрес (например, `192.168.1.50`).
5. Откройте браузер на телефоне или компьютере, подключенном к той же домашней сети, и введите этот IP-адрес.
6. Откроется страница настройки. Вставьте туда ваши **Client ID**, **Client Secret** и **Refresh Token**, которые вы получили ранее.
7. Нажмите **Save**. Устройство перезагрузится, подключится к Spotify и начнет отображать текущий трек!

## 🧑‍💻 Для разработчиков (Ручная сборка)

Если вы хотите изменить интерфейс или код:
1. Установите VS Code и расширение **PlatformIO**.
2. Откройте папку `firmware/` в VS Code.
3. Внесите изменения в код.
4. Нажмите кнопку "Upload" (стрелочка вправо) в нижней панели PlatformIO, чтобы скомпилировать и прошить устройство.
